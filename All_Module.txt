================================================================================
Website VGA Master hoạt động theo mô hình Full-stack Web Động (Client - Server):
1. Phía Máy khách (Client-side Frontend):
   - Xây dựng bằng HTML5, CSS3 và JavaScript thuần (Vanilla JS).
   - Đảm nhiệm giao diện hiển thị, giỏ hàng, tìm kiếm và gửi yêu cầu (Request).
2. Phía Máy chủ (Server-side Backend):
   - Xây dựng trên nền tảng Node.js và framework Express (tệp server.js).
   - Đảm nhiệm phục vụ tệp tin tĩnh và cung cấp 5 cụm RESTful API dữ liệu.
3. Cơ sở dữ liệu tập trung (Database Persistence):
   - Lưu trữ toàn bộ dữ liệu tại tệp database.json trên máy chủ.
   - Dữ liệu được ghi nhận vĩnh viễn, không bị mất khi đóng trình duyệt hay đổi máy.

PHẦN 5: DANH SÁCH RESTFUL API & CƠ CHẾ WEB ĐỘNG (server.js)
================================================================================
Máy chủ Backend xây dựng trên Node.js + Express, cung cấp 5 cặp REST API chính thức:

1. GET & POST /api/du-lieu
   - Phương thức GET : Trả về toàn bộ dữ liệu hệ thống (sản phẩm, tài khoản, đơn hàng, đánh giá).
   - Phương thức POST: Lưu toàn bộ cấu trúc dữ liệu vào tệp tin database.json trên máy chủ.

2. GET & POST /api/sanpham
   - Phương thức GET : Lấy danh sách 15 sản phẩm card đồ họa từ database.json.
   - Phương thức POST: Cập nhật, thêm mới, sửa giá, hoặc xóa sản phẩm vĩnh viễn trên server.

3. GET & POST /api/donhang
   - Phương thức GET : Lấy toàn bộ đơn hàng khách đã đặt trên hệ thống.
   - Phương thức POST: Lưu đơn hàng mới khi khách thanh toán hoặc cập nhật tiến trình 5 bước giao hàng.

4. GET & POST /api/nguoidung
   - Phương thức GET : Lấy danh sách tài khoản khách hàng và quản trị viên.
   - Phương thức POST: Lưu tài khoản mới khi đăng ký hoặc cập nhật trạng thái khóa/mở khóa tài khoản.

5. GET & POST /api/danhgia
   - Phương thức GET : Lấy danh sách đánh giá sao và bình luận sản phẩm.
   - Phương thức POST: Lưu đánh giá mới hoặc xóa đánh giá vi phạm từ trang quản trị Admin.

CƠ CHẾ ĐỒNG BỘ CLIENT - SERVER (storage.js):
- Khi trang web tải lên: Gọi API 'GET /api/du-lieu' để tải dữ liệu mới nhất từ server về trình duyệt.
- Khi có thao tác thay đổi (thêm sản phẩm, đặt hàng, khóa tài khoản...): Trình duyệt tự động gửi 'POST /api/...' tương ứng lên server để ghi ngay lập tức vào database.json.
- Kết quả: Dù đóng trình duyệt, mở máy tính khác, hoặc khởi động lại server thì dữ liệu vẫn còn nguyên 100%!
